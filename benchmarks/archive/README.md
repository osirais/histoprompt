# Archived benchmark experiments

These runs are retained for audit history but are not the current benchmark entry points.

- `lung-prompt-screens/v1` through `v5` are successive rapid prototypes on small LC25000 lung subsets. Later versions reuse many of the same images, so they are not independent confirmation runs.
- `shared-prompt-comparisons/300` and `1000` applied one MUSK-selected phrase to all four models. That experiment showed the phrase was not portable, but it is superseded by the per-model searches in `../../lc25000-tuning/results/`.

Use [`../RESULTS.md`](../RESULTS.md) for the current comparison.
